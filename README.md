## 🤔 What is This?

**Not-Weak-Mind (EduScreen)** is a simple questionnaire created by a high school student to help people think about different learning styles and potential learning challenges.

### Simple Purpose
The tool asks **80 questions** to explore:
- Reading & spelling challenges
- Math difficulty
- Writing challenges
- Attention & focus
- Organization & planning
- Processing speed
- Memory issues
- Anxiety about learning
- Motivation
- And more...

### Key Features (v1.2.0 Overhaul)
- 🌐 **Instant Bilingual Support**: Full English and Hindi (`हिन्दी`) localization toggle.
- 🔊 **Integrated Text-to-Speech**: Browser-native Web Speech API reads questions aloud for students with reading delays.
- 💾 **Resilient Offline Session Auto-Save**: Progress is saved locally after every question; never lose answers on refresh.
- ⬅ **Bi-Directional Navigation**: Change answers anytime with `< Previous Question` navigation.
- 📊 **Dual Visualizations**: 15-Domain Bar Chart + 4-Quadrant Multidimensional Cognitive Radar (Spider) Chart.
- 📏 **Assistive Neurodiversity Tools**: Reading ruler overlay, Atkinson Hyperlegible accessible font, and font scaler (`A-` / `A+`).
- 📁 **Multi-Format Clinical Export**: Clean print/PDF layout, raw JSON psychometric payload, and tabular CSV for school records.
- 📱 **Universal PWA & Android Compatibility**: Runs 100% offline; Android APK supports Android 7.0+ (API 24+).

## 🚀 How to Use

### Step 1: Open the Tool
Go to: **[https://aryanbarnvanshi-dev.github.io/Not-Weak-Mind/](https://aryanbarnvanshi-dev.github.io/Not-Weak-Mind/)**

### Step 2: Choose Mode
- **Student Mode**: If you're a student answering about yourself
- **Teacher/Parent Mode**: If you're observing a student

### Step 3: Answer Questions
- 80 questions across 15 categories
- Options: Never/Rarely, Sometimes, Often, Almost Always
- Use **🔊 Read Aloud** if you prefer audio narration

### Step 4: Review Your Report
- Review the 15-domain score bar chart and 4-quadrant cognitive radar
- Review identified strengths and tiered accommodations (Classroom, Home, Assistive Tech)
- Print or save as PDF, JSON, or CSV
- **Share with a qualified specialist if you see areas of concern**

## 🧠 What It Screens (15 Categories)

1. **Dyslexia Indicators** - Reading, spelling, and decoding challenges
2. **Dyscalculia Indicators** - Number sense, math symbols, and arithmetic
3. **Dysgraphia Indicators** - Handwriting legibility, grip fatigue, and written expression
4. **Attention Difficulty** - Focus, distractibility, and impulsivity
5. **Executive Function** - Planning, organizing, and task transitions
6. **Processing Speed** - Pace of completing cognitive tasks
7. **Working Memory** - Holding and manipulating information
8. **Recall Difficulty** - Long-term fact retrieval and recognition
9. **Learning Anxiety** - Stress and negative self-talk related to schoolwork
10. **Test Anxiety** - Physical panic and mental blanking during exams
11. **Motivation** - Academic engagement and frustration tolerance
12. **Sensory Sensitivity** - Reactions to classroom noise, light, or touch
13. **Fine Motor** - Hand dexterity, pencil grip, and tool precision
14. **Social Learning** - Interpreting social cues, sarcasm, and peer dynamics
15. **Communication** - Expressing thoughts verbally and vocabulary retrieval
